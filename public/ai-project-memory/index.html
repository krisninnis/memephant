FAQ

AI project memory questions

What is AI project memory?

AI project memory is a persistent record of a project — its goals, decisions, stack, and next steps — that you can give to any AI tool so it understands the work without you re-explaining it. The AI chat itself stays stateless; the memory lives with you and travels between tools.

Why do AI tools forget my project between sessions?

ChatGPT, Claude, and Gemini each keep only their own limited, separate context. Start a new chat, switch tools, or come back days later and that context is gone, so you have to describe your project from scratch again.

How does Memephant give my projects persistent memory?

You store each project once in Memephant. When you open an AI tool, you copy a Context Passport — a handoff shaped for that platform — and paste it at the start of a chat. Paste the AI's reply back and Memephant shows a diff before updating, so your project memory stays current.

Where is my project memory stored?

Memephant is local-first: your project memory lives on your device in plain files by default. Cloud backup is optional and opt-in, and no account is needed to create projects or generate handoffs.

Which AI tools does it work with?

Memephant generates handoffs shaped for ChatGPT, Claude, Perplexity, Gemini, Codex, Grok, and local LLMs. You copy and paste each handoff yourself, so it works with any tool that accepts pasted text.
