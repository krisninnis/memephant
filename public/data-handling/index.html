Data Handling Summary

Memephant is local-first. This page summarizes the main data flows.

Stored Locally

  • Project memory, checkpoints, and settings.
  • Personal Memory Vault data.
  • Passport profile data.
  • Optional offline sync queue data when cloud backup is enabled and temporarily unavailable.

User-Controlled Exports

Handoffs are generated locally and copied only when you click a copy/export action. Export sanitisation and linked-folder path redaction are part of the export boundary.

Optional Network Features

  • Cloud backup: requires sign-in and sends project data to the configured backend.
  • Billing: uses hosted checkout and billing provider flows.
  • Desktop updates: checks signed release metadata when used in the installed desktop app.
  • Crash reporting: optional and disabled by default.

Not Included Automatically

  • Personal Memory Vault contents are not included in project exports by default.
  • Memephant does not send project data directly to AI providers.
  • Telemetry and analytics are not required to use the app.
